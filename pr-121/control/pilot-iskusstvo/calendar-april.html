русским источникам до сборки страницы. Привязка: **[Р]** рождение · **[И]**
событие · **[К]** календарный якорь · **[У]** условная (для искусства привязка
не обязательна — решение Сергея 04.09.2026; художник может входить в год
несколько раз с разными картинами).

Механика по умолчанию — эталон зала Айвазовского (зум + «найди деталь» ✅);
вау-добавки страницы 1 января (шторка эскиз/полотно, ставка до ответа, звук
места, чат по подлинным цитатам, развилка судьбы, праздничный режим)
переиспользуются по сюжету дня — стандарт «вау-эффект, не самое дешёвое»
(Сергей, 04.09).

Январь, февраль и март — прямого «да» Сергея на их состав не найдено, записи
в реестре утверждений (docs/approvals/calendar-approvals.json) нет: ждут «да» Сергея.
