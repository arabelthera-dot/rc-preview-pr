# Календарь — январь
## Музей русского искусства

**Статус:** УТВЕРЖДЁН — собран 04.09.2026, пересобран 05.09.2026 (v3 —
переписаны хуки 2 и 9 января); правки v3 входят в утверждённый состав.
Сергей, 08.10.2026, дословно: «Я по всем музеям на все 365 дней утвердил дни календаря»;
сверка `python3 tools/approvals.py status --museum iskusstvo` 08.10.2026 — месяц утверждён, изменено после «да» 0. Состав меняется только показом и «да» (гейт, museum-core §1-бис). Даты — по НОВОМУ стилю,
как в движке `calendar-art.js`. 🔎 — дата/атрибуция сверяется по русским
источникам (culture.ru, Третьяковская галерея, Русский музей) до сборки
страницы, не после.

**Решение Сергея 04.09.2026 (дословно):** «Для музея искусства нет надобности
привязываться всегда к каким-то датам, потому что у разных художников могут
быть несколько интересных картин, которые будут размещаться, и они могут не
привязываться к датам. Для этого конкретного музея это не обязательно».
Отсюда: [У]-слоты — норма, художник может встречаться в году несколько раз
с разными картинами. При [У] формулы «в этот день» запрещены (museum-art).

Привязка даты: **[Р]** рождение художника · **[И]** событие · **[К]**
календарный якорь · **[У]** условная (картина без точной даты).

Механика по умолчанию — эталон зала Айвазовского: глубокий зум с деталями +
игра «найди деталь» ✅ (движок уже есть). Где скан слабее 2500 px —
ограниченный зум с честной пометкой (профиль museum-art).

Страниц пока нет ни у одного дня: колонка «куда ведёт» появится при
производстве. Есть только три страницы зала Айвазовского (июль, май).
